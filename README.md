# GOLANG_BASICS 🚀

A collection of my GoLang learning journey, from the basics to backend development.

I created this repository to keep all the code I write while learning Go in one place. Most of the programs are small and simple, written mainly to understand how things work by actually coding them.

## 📌 About This Repository

This is a personal learning repository.

I'm learning Go step by step, writing code, making mistakes, fixing them, and gradually moving towards building real backend applications.

The code may not always be perfect, but that's the point of this repository. It's a record of my progress.

## 🛠️ Setup

Install Go on your system and check the installation:

    go version

Clone this repository:

    git clone https://github.com/samiralam321/GOLANG_BASICS.git

Go inside the repository:

    cd GOLANG_BASICS

Run a Go program:

    go run main.go
